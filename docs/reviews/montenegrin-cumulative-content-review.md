## 1. Cumulative sentence frames (revision 9, days 27–200)

Each frame is combined with a noun below, e.g. "Ovo je mama." / "Gdje je kafa?".

| Frame | English | Teaching note shown to learners | Verdict | Correction |
|---|---|---|---|---|
| Ovo je … . | This is … | Ovo = this; je = is. Put a familiar naming word after “Ovo je”. |  |  |
| Gdje je … ? | Where is … | Gdje = where; je = is. “Gdje je” asks where one person or thing is. |  |  |
| Tu je … . | Here is … | Tu = here; je = is. “Tu je” points out one person or thing. |  |  |
| To nije … . | That is not … | To = that; nije = is not. “To nije” says what something is not. |  |  |

## 3. Topic sentence lessons (revision 8; also used in listening practice)

### Make and order a drink (source days 27–30)

Pattern note: Hoću means “I want”. After it, voda becomes vodu and kafa becomes kafu: Hoću vodu.

| Montenegrin | English | Verdict | Correction |
|---|---|---|---|
| Hoću vodu, molim. | I want water, please. |  |  |
| Dodaj limun u čaj. | Add lemon to the tea. |  |  |
| Sipaj sok u čašu. | Pour juice into the glass. |  |  |
| Čaj je topao. | The tea is warm. |  |  |
| Mogu li dobiti vodu? | Can I have water? |  |  |
| Neću šećer u čaju. | I do not want sugar in my tea. |  |  |

Dialogue:

| Role | Montenegrin | English | Verdict | Correction |
|---|---|---|---|---|
| Host | Šta želiš da piješ? | What would you like to drink? |  |  |
| Guest | Hoću čaj, molim. | I want tea, please. |  |  |
| Host | Želiš li limun? | Would you like lemon? |  |  |
| Guest | Da, hvala. | Yes, thank you. |  |  |

### Share a meal (source days 31–35)

Pattern note: Imam means “I have”. Nemam means “I do not have”. Use the whole sentence to say what is on your plate.

| Montenegrin | English | Verdict | Correction |
|---|---|---|---|
| Imam hljeb i sir. | I have bread and cheese. |  |  |
| Hoću još supe, molim. | I want more soup, please. |  |  |
| Dodaj so u supu. | Add salt to the soup. |  |  |
| Jaja su na stolu. | The eggs are on the table. |  |  |
| Nemam kašiku. | I do not have a spoon. |  |  |
| Ručak je spreman. | Lunch is ready. |  |  |

Dialogue:

| Role | Montenegrin | English | Verdict | Correction |
|---|---|---|---|---|
| Host | Želiš li još supe? | Would you like more soup? |  |  |
| Guest | Da, molim. | Yes, please. |  |  |
| Host | Evo hljeba. | Here is some bread. |  |  |
| Guest | Hvala, ručak je ukusan. | Thank you, lunch is delicious. |  |  |

### Buy ingredients (source days 36–40)

Pattern note: Koliko košta…? asks “How much does … cost?” Treba mi… means “I need …”.

| Montenegrin | English | Verdict | Correction |
|---|---|---|---|
| Koliko košta sir? | How much does the cheese cost? |  |  |
| Treba mi jedna kesa. | I need one bag. |  |  |
| Hoću dvije jabuke. | I want two apples. |  |  |
| Imate li paradajz? | Do you have tomatoes? |  |  |
| Stavi jabuke u kesu. | Put the apples in the bag. |  |  |
| Ovaj sir je dobar. | This cheese is good. |  |  |

Dialogue:

| Role | Montenegrin | English | Verdict | Correction |
|---|---|---|---|---|
| Customer | Dobar dan. Imate li jabuke? | Hello. Do you have apples? |  |  |
| Seller | Da, izvolite. | Yes, here you are. |  |  |
| Customer | Hoću dvije jabuke, molim. | I want two apples, please. |  |  |
| Seller | Evo. Hvala! | Here you go. Thank you! |  |  |

### Work in the garden (source days 41–45)

Pattern note: U bašti means “in the garden”. Use a whole sentence to say where something grows or what you do there.

| Montenegrin | English | Verdict | Correction |
|---|---|---|---|
| Radim u bašti. | I work in the garden. |  |  |
| Zalij biljke, molim. | Water the plants, please. |  |  |
| Paradajz raste u bašti. | Tomatoes grow in the garden. |  |  |
| Treba mi voda. | I need water. |  |  |
| Imamo svježe povrće. | We have fresh vegetables. |  |  |
| Stavi cvijeće na sto. | Put the flowers on the table. |  |  |

Dialogue:

| Role | Montenegrin | English | Verdict | Correction |
|---|---|---|---|---|

| Imam vremena danas. | I have time today. |  |  |

## 4. False-Friend Detective case packs

### Case pack 1 (milestone 10)

| Word | Sentence | Correct meaning | Other choices | Explanation | Clue words | Verdict | Correction |
|---|---|---|---|---|---|---|---|
| grad | Padao je grad cijelo popodne. | hail | city, work | Here “grad” means hail: frozen rain fell all afternoon. In another sentence, the same word can mean city. | — |  |  |
| kosa | Ona ima dugu kosu. | hair | slope, scythe | “Kosu” is the sentence form of “kosa” meaning hair. Kosa can also mean a slope or a scythe in other contexts. | — |  |  |
| pravo | Idi pravo do trga. | straight ahead | law, right / entitlement | After the verb “go,” pravo means straight ahead. The same form can refer to law or a right elsewhere. | — |  |  |
