# Proposal: Add visual learning scenes

## Why

Text-first lesson cards do not take advantage of visual recognition and make the learning experience feel disconnected from the illustrated voyage. Learners should encounter vocabulary in memorable Montenegro-oriented contexts and continue seeing meaningful visual cues during practice.

## What changes

- Add an original contextual scene to supported topics.
- Carry topic-specific visual cues into discovery, recall, and matching.
- Keep text and accessible descriptions available alongside every essential visual.
- Use Colors as the reference implementation before expanding to other topics.
